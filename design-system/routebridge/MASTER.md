# RouteBridge design system (source of truth)

Generated with ui-ux-pro-max, then adapted: kept the warm teal brand instead of the suggested blue.

| Token | Value | Use |
|---|---|---|
| `--teal` | #19796e | brand, links, selected states |
| `--rb-accent` | #d9560b | the one primary action (New order), attention marks |
| `--paper` / `--white` | #f4f6f3 / #fffdf9 | page / surfaces |
| Headings | Newsreader 600 | warm, human |
| Body / UI | Manrope 400-700 | readable at small sizes |
| Radius | 12px cards, 8px controls | |
| Motion | 140-240ms, ease `cubic-bezier(.2,.7,.2,1)`, off under reduced-motion | |

Rules: 44px minimum tap targets; visible focus ring on every control; tabular numerals for money and counts; status never by colour alone (label + dot); one orange action per screen; use SVG icons, not emoji.
